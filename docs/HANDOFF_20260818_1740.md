## 踩坑记录（下次复用）

1. **aiortc 1.14+ 要求 py3.10+**：系统 `/usr/bin/python3` 是 3.9 → venv 必须用 `/opt/homebrew/bin/python3.12` 创建
2. **TTS 插件白名单**：`avatars/base_avatar.py` 的 `_tts_modules` dict 是硬编码，新 TTS 必须加进去（`'MiniMax': 'tts.MiniMax'`），否则 "TTS module not found"
3. **TTS 模块缺失只 log 不抛异常**：导致 `self.tts` 属性缺失 → `render()` 崩 `AttributeError`（已改为抛异常方便诊断）
4. **MiniMax Free 档 RPM 限流**：分句流式逐句调 API 会触发 RPM 超限 → 必须句间节流 + 限流退避重试
5. **MiniMax 日额度会烧穿**：长文本（3000+ 字）分句暴发请求直接打穿 daily 0% → 长文本用 EdgeTTS，MiniMax 留短对话
6. **Wav2Lip 实时 fps 12-17**：Mac MPS 极限低于 25fps 目标，短对话可接受
