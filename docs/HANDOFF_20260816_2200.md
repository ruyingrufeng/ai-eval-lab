## 踩坑记录（避免复用）

1. **本机 HTTPS 代理 7892 已死**：所有 curl/Python 请求走 `HTTPS_PROXY=127.0.0.1:7892` → ConnectionRefused。**对策**：`unset HTTP_PROXY HTTPS_PROXY; export NO_PROXY='*'; export HF_ENDPOINT=https://hf-mirror.com`。
2. **SenseVoice 输出含 emotion/event tags**：`<|zh|>` `<|HAPPY|>` `<|Speech|>` `<|withi tn|>` 包裹识别结果，CER 计算必须 `re.sub(r'<[^<>]*>', '', text)` 剥离，否则数字爆炸。
3. **SenseVoice 无 VAD 时间戳分段**：`segments` 只返回 1 段（汇总整段），按时间窗口切 CER 失真。本轮用"全文对齐"算 CER（更准）。
4. **FunASR 走 modelscope 不走 HF**：模型下载走 `https://www.modelscope.cn`，缓存路径 `~/.cache/modelscope/hub/`，与 HF 不同。
5. **pip 默认 stdout 缓冲**：Fish Speech 装机脚本（pip install 多个依赖）stdout 不刷，进程看似卡死——必须加 `PYTHONUNBUFFERED=1` 或 `python -u`。
6. **openai-whisper SHA256 checksum 不匹配**：`~/.cache/whisper/small.pt` 损坏触发自动重下（461MB），进度只到 19% 时被截断 = 被 SIGTERM 杀掉（不是网速问题）。
7. **ChatTTS 模型不在**：`chattts_generate.py` 默认路径 `~/voice-tools/models/chattts/2Noise/ChatTTS` 不存在，需手动 HF 下载 ~400MB。
