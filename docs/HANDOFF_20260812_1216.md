- ComfyUI C1 是可靠串行队列，不是 GPU 并行；
- RealVisXL 更快（56s/张），但颜色遵循差（30%），prompt 复杂时不可靠；
- Flux Q4 更慢（288s/张），颜色遵循完美（100%），平均 89.4 分，可直接使用率 80%；
- 当前 27B 64K×2 配置不适合与 ComfyUI 共存。

## 已知问题与注意事项

- 本机 swap 绝对值原本就高，必须使用测试前后增量；
- localhost 请求需显式禁用代理继承；
- Flux 有 `text_projection.weight` 缺失警告但能完成；
- 不能用进程 RSS 代替 Apple 统一内存；
- 不能用身份 embedding 或自动颜值分代替用户审美；
- llama 路由卸载模型使用 `POST /models/unload`，不要直接结束派生子进程；
- **本次新增**：盲评脚本需要 `-u` 强制无缓冲输出，否则 stdout 被 Python 默认缓冲时无法实时看到进度；
- **本次新增**：盲评脚本运行时 Hermes `process wait` 600s 超时会让 session 标 exited，但实际 OS 进程仍存活——以 `ps -p PID` 为权威；
- **本次新增**：ComfyUI 重启时必须用 `pkill -f "ComfyUI/main.py"` 清理旧的再启，否则会双 ComfyUI 争同一端口；新进程起来后**不要再用** `pkill -f "ComfyUI/main.py"`，否则会误杀新进程。
