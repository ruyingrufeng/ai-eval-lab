# HANDOFF_20260813_1846.md — Flux 全身像方法评测交接

## 任务目标

本项目不是单纯生产图片，而是持续评测工具并找出最佳使用方法。本轮聚焦两个问题：

1. Flux 能否稳定生成完整全身像；
2. Flux OpenPose ControlNet 是否必须进入默认工作流。

## 当前结论

### 已通过：全身构图

- 6/6 张均完整显示头顶、身体和双脚。
- 不使用 OpenPose 的 A/B 两组共 4/4 张完整全身。
- 因此 Flux 本身可以生成全身像，OpenPose 不是全身构图的必选依赖。
- 默认使用强化全身提示词；OpenPose 仅在姿态、人物占比或站位必须精确复现时启用。

### 未通过：数字人身份一致性

- 用户复核认为人脸仍有明显“飘逸”，准确含义是身份漂移。
- 不同 seed 之间的脸型、眉眼、发型变化明显，目前只能维持“同类型人物”，不能稳定证明是“同一个人”。
- 同一 seed 的 A/B 人脸接近，说明强化构图提示词不是身份漂移的主因。
- OpenPose 组的身份漂移更明显，说明姿态控制可能进一步挤压身份控制效果。
- 旧评测中“Flux IP-Adapter 100% 脸还原”“可作为同一角色多张图生产方案”的结论，不能直接外推到本轮严格全身小脸场景。
- 本轮只能宣布“全身构图通过”，不能宣布“数字人工作流整体通过”。

建议实验：

## 当前阻塞与风险

- 全身图中的脸占画面较小，单纯 IP-Adapter 对局部五官的约束可能不足。
- 权重继续升高可能改善身份，但也可能带来构图、服装和自然度损失。
- OpenPose 与身份控制可能竞争约束，不应与锁脸权重实验同时变化。
- 目前只有 2 个种子，足以筛选方法，不足以宣称稳定生产；最终推荐至少补到 8–12 个种子。
