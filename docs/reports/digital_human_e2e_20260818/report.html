产物预览

SadTalker 嘴型同步 + MiniMax 中文音频

完整 12.5s 数字人片段：MiniMax 温柔学姐中文 + 256x256 嘴型同步。音频/视频时长对齐（12.67s/12.6s），是端到端最简闭环。

LivePortrait 表情迁移参考

720x1280 表情驱动 + concat 对比版。3.12s，仅展示表情层，未带音频（输入是驱动视频而非音频）。

判定

verified SadTalker 单链路：音频→嘴型同步完整可生产，12s 内音频 ~3:22 渲染，256 模式内存友好（~1.5GB）

verified LivePortrait 单链路：静态图→表情迁移清晰，1:04 跑 3s 视频

架构问题 SadTalker + LivePortrait 串联 = 当前不直接成立。两个工具输入形态不同（音频 vs 驱动视频），业务"既会说话又有表情"需要混合链路或等待端到端音频→表情模型

业务定位（阿伟建议）

  • 数字人讲解/播客片段（音频驱动嘴型） → 直接用 SadTalker 256，production-ready
  • 头像替换/驱动片段特写（视频驱动表情） → 直接用 LivePortrait，production-ready
  • "既会动又有表情" → 当前没有一键方案。两条路：
    • 路 A：SadTalker 出嘴型 → 抽帧 → LivePortrait 二次精修（成本高，工作量待验证）
    • 路 B：等 EchoMimic（Mac 当前 blocked，等 MPS fp16 支持）/ 或 Wav2Lip（轻量备胎待测）

关键命令

# 1. MiniMax-TTS（温柔学姐）
mmx speech synthesize \
  --text "$(cat sample.txt)" \
  --voice "Chinese (Mandarin)_Gentle_Senior" \
  --out tts_dh_demo.wav

# 2. SadTalker 256（嘴型）
source ~/voice-tools/venv-sadtalker/bin/activate
cd ~/voice-tools/SadTalker
PYTORCH_ENABLE_MPS_FALLBACK=1 PYTORCH_MPS_HIGH_WATERMARK_RATIO=0.0 \
python inference.py \
  --source_image <人脸图.jpg> \
  --driven_audio  \
  --size 256 --batch_size 2 --pose_style 0 \
  --result_dir <输出目录>

# 3. LivePortrait（表情）
source ~/voice-tools/venv-liveportrait/bin/activate
cd ~/voice-tools/LivePortrait
PYTORCH_ENABLE_MPS_FALLBACK=1 \
python inference.py \
  -s <人脸图.jpg> -d <驱动视频.mp4> -o <输出目录>

# 4. ffmpeg 合并
ffmpeg -i sadtalker.mp4 -i tts.wav -c:v copy -c:a aac -shortest e2e.mp4
