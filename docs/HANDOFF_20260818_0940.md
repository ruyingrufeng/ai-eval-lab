## 关键命令

```bash
# 1. MiniMax-TTS（温柔学姐）
mmx speech synthesize --text "..." --voice "Chinese (Mandarin)_Gentle_Senior" --out tts.wav

# 2. SadTalker 256（嘴型）
source ~/voice-tools/venv-sadtalker/bin/activate
cd ~/voice-tools/SadTalker
PYTORCH_ENABLE_MPS_FALLBACK=1 PYTORCH_MPS_HIGH_WATERMARK_RATIO=0.0 \
python inference.py --source_image X --driven_audio Y --size 256 --batch_size 2 --pose_style 0 --result_dir Z

# 3. LivePortrait（表情）
source ~/voice-tools/venv-liveportrait/bin/activate
cd ~/voice-tools/LivePortrait
PYTORCH_ENABLE_MPS_FALLBACK=1 python inference.py -s X -d Y -o Z

# 4. ffmpeg 合并
ffmpeg -i sadtalker.mp4 -i tts.wav -c:v copy -c:a aac -shortest e2e.mp4
```

## 关键发现

1. **输入形态不兼容**：
   - SadTalker 接收静态图 + **音频** → 输出嘴型同步视频
   - LivePortrait 接收静态图 + **驱动视频** → 输出表情迁移视频
   - 两个工具**不能直接串联**：SadTalker 输出是视频，不是 LivePortrait 期望的输入

2. **业务路径**：
   - "说话" → SadTalker ✅
   - "做表情" → LivePortrait ✅
   - "既说话又做表情" → 当前没有一键方案，需混合链路或等新模型

3. **耗时基准**（12s 音频）：
   - SadTalker 256：~3:22 渲染
   - LivePortrait 3s：~1:04 渲染
