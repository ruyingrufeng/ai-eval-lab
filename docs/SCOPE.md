# 项目边界

## 包含

- 工具、推理后端和模型的发现、选型、安装、配置、升级与卸载说明；
- 可复现的功能、质量、性能、稳定性、隐私和许可证验证；
- 模型文件校验、版本锁定、缓存规划、API 兼容测试；
- 工作流模板的技术验证；
- 测试结果与“推荐 / 备选 / 淘汰 / 待验证”决策记录。

## 不包含

- 选题、写稿、作图、剪辑、小说连载等实际内容生产；
- 内容资产库、发布排期、账号运营或平台自动发布；
- 保存真实用户的敏感内容、未授权肖像或声音素材；
- 对外提供公开生成服务。

## 输出接口

通过验证的能力最终应以以下一种或多种形式交付给其他项目：

- OpenAI 兼容的本地 HTTP API；
- ComfyUI API 工作流 JSON；
- 稳定的 CLI 命令；
- 固定版本的 Python/Node 环境；
- 含模型 ID、量化格式、哈希、许可证和推荐参数的清单。

## 成人尺度测试边界

成人尺度仅用于评估模型对合法成人题材的可控性、拒答特征、提示遵循、输出隔离和审计能力。测试集只使用抽象文本描述、合成人物或已明确授权且年龄可验证的成年人素材。硬性禁止：

- 任何未成年人或年龄不明主体；
- 非自愿、胁迫、偷拍或性暴力材料；
- 未经授权的真人色情化、换脸或声音克隆；
- 绕过许可证、平台政策或当地法律的测试；
- 将敏感测试样本或输出提交到 Git。
