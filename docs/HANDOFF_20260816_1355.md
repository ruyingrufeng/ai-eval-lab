## 踩坑记录（避免复用）

1. **8086 router 空 `default` preset 陷阱**：`[*]` 全局段被 router 注册为无 `-m` 的 `default` preset，请求 `model=default` 会卡在 `ensure_model` 无限等待。**评测必须显式传模型 ID `qwen3.6-27b-fable`**（昨天评测同样用此 ID）。查询用 `curl /v1/models` 取 `data[*].id`。
2. **脚本用连字符命名导致 import 失败**：`benchmark-st-longsession.py` 不能直接 `import module_name`，冒烟测试需用 `importlib.util.spec_from_file_location` 加载。
3. **后台进程 stdout 重定向 + `process wait` 误报**：`> log 2>&1` 后 `process` 的 wait 会立即返回，但脚本仍在运行；改用轮询 `grep -c "stop" log` 判断真实进度。
