## 使用边界

- 仅推荐串行、明确字段契约、可用 JSON schema 判定的文件任务。
- 不覆盖 bash、grep/glob、web、skill、subagent、workflow、goal 或开放式研究。
- 不覆盖 16.5K 槽位以上上下文。
- Qwen Ridge 仍是通用 dsh 配置默认。

## 使用入口

1. 先在 dsh 设置中显式选择 `glm4.7-flash-local/glm4.7-flash`。
2. 通过 `scripts/dsh-glm47-validated.sh "任务"` 运行；路由不是 GLM 时脚本会拒绝执行。
3. 每个任务必须配套 `benchmarks/schemas/` 下的 schema，并用 `scripts/validate-json-schema.py` 独立验收。
