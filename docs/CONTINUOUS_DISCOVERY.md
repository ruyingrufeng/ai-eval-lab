# 工具与模型持续发现制度

记录时间：2026-08-12 11:11:02 +08:00。

内容生产工具与模型选型是动态过程。当前推荐只代表最近一次核验时，在本机硬件、软件版本、许可证和目标工作流下的判断，不代表永久结论。

## 检查节奏

### 每周快速检查

每周检查文章、图片、视频、小说、数字人五类能力是否出现：

- 新模型、重要版本或新量化格式；
- 新的 MLX、Metal、MPS 或 Apple Silicon 支持；
- 原候选的许可证、使用限制或维护状态变化；
- 能替代当前失败路线的新控制、语音、视频或数字人组件；
- 本机已有工具的新版本是否解决已记录的问题。

周检只做发现和登记，不自动安装、升级、下载大权重或修改服务。

### 每月深度复核

每四次周检后，对累计候选做一次排序：

1. 清理重复、停止维护或许可证不适配的候选；
2. 检查官方模型卡、仓库 release、issue 与硬件要求；
3. 按内容类型重新计算测试优先级；
4. 最多挑选少量候选进入安装或基准测试提案；
5. 只有获得明确测试任务后才执行下载和安装。

### 触发式复检

以下变化不等到下个周期：

- 当前推荐工具出现严重故障、安全问题或许可证变化；
- 新版本明确增加 Mac/MPS/MLX 支持；
- 新模型在同等质量下显著降低内存、磁盘或推理时间；
- 某内容类型新增生产需求，当前矩阵没有覆盖；
- 本机系统、Python、Node、ComfyUI 或推理后端发生大版本升级。

## 每次检查的记录字段

- `discovered_at`：首次发现时间；
- `source_published_at`：官方发布或版本时间，未知则为 `unknown`；
- `last_checked_at`：最近核验时间；
- `content_types` 与 `pipeline_stages`：匹配哪些内容类型和环节；
- `host_fit`：`likely / uncertain / poor`；
- `license_status`：`compatible / review_required / incompatible / unknown`；
- `adult_capability`：只记录合法成年人内容的支持、受限或未知；
- `delta`：相对现有工具真正改善了什么；
- `decision`：`watch / propose_test / reject / superseded`。

所有时间带时区或注明精度。网络资料只允许把条目提升为候选，必须经过本机测试才能成为推荐项。

## 候选进入测试的条件

候选至少满足以下一项才建议测试：

- 补齐当前明确缺口；
- 在质量、速度、内存、稳定性、控制能力或许可证上可能有显著改善；
- 维护更活跃，能替换当前脆弱或停止维护的依赖；
- 具备当前不存在的可靠 Apple Silicon 路径。

仅有热度、榜单名次或演示视频，不足以触发下载。

## 周检输出

每次只输出变化：

- 新增候选；
- 候选状态变化；
- 许可证或 Mac 支持变化；
- 建议进入测试的项目；
- 没有实质变化时，只记录检查时间。

结果应更新 `registry/discovery_log.yaml`，必要时同步 `registry/content_type_matrix.yaml` 和 `registry/candidates.yaml`，并按共享记忆时间规范追加交接记录。
