长度结论

此前“3.8 写不长”的判断被推翻。它本轮同题写到 1965 字，1500 字刻度题写到 1513 字。

真正的问题是波动：同一都市奇幻题已有 854 与 1965 两个样本；800 字题默认写 536，强长度提示后写 1048。更适合用段落数和情节点控制，而不是硬字数。

文笔与角色声音

Fable：更克制、对白更有记忆点、人物关系与因果更清楚。渡轮篇整体明显优于 3.8。

“你就这么急着把我的灵魂称重标价？”

3.8：更愿展开动作和环境，立场并不软；但常用括号舞台动作、通用强情绪句式和突然的大段背景解释，人物关系偶有混乱。

“我是老板，不是你的谈判筹码。至于拆不拆，我说了算，而我的答案是：不。”

角色卡与世界书

  • 两者都坚持反对拆电影院，并记住最终提醒三项。
  • 3.8 正确纠正银币而非金币；3.6 一度错改成铜钱。
  • 3.6 出现一次用户动作接管；3.8 本轮没有。
  • 两者都有门锁、身体限制或债务状态连续性错误。
  • 两者都会编造共同经历；3.8 更容易戏剧化扩写未给定的家族与世界设定。

成人场景

两者均无拒绝，长度均通过，撤回同意后均停止。3.6 更直接、紧凑，立即完全退出；3.8 更长但偏说明式，并在下一轮重复了已经完成的退出动作。两者均有各自的动作连续性瑕疵。

部署与最终建议

  1. 8086 继续保留 3.6 Fable 单槽 64K。
  2. 撤回“3.8 不适合 ST”，改成“适合 ST、暂不替换 Fable”。
  3. 3.8 可按需用于更长普通/成人回复、世界书实验和一体化视觉；使用时停独立 7B 视觉。
  4. 3.8 角色卡增加：禁止编造共同经历、禁止括号舞台动作、关键状态不得自行补全；短聊目标长度下调约 20%。
  5. 最终文风选择应再用用户真实角色卡做 15–20 轮 A/B。
