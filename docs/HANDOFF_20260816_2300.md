## ChatTTS 拉通路径（重要，避免复用）

1. **下载源**：hf-mirror 89KB/s 且断续（不可靠）→ **modelscope `AI-ModelScope/ChatTTS`** 14MB/s（快 200 倍）。
2. **文件**：9 个 safetensors（DVAE 60MB / Decoder 104MB / Embed 146MB / Vocos 54MB / gpt/model 853MB + 4 个 json），放 `~/voice-tools/models/chattts/2Noise/ChatTTS/asset/`。
3. **坑**：modelscope 文件续传 `-C -` 会截断（DVAE 下成 41MB），必须校验 `stat -f %z` 与期望一致再认为成功；sha256 校验严格（格式 .safetensors 与 pip 包 0.2.5 匹配）。
4. **调用**：`chattts_generate.py` 不支持 `--format`（只输出 wav）；`--speed 1.0 --temperature 0.3 --seed 42` 稳定。
5. 合成耗时 15-20s/用例（CPU），音频时长合理，无截断。
