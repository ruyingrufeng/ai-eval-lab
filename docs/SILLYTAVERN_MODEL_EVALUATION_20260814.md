# SillyTavern 本地模型首轮评测（2026-08-14）

## 结论

当前本机候选中，`Qwen3.6-35B` 使用调参档最适合作为 SillyTavern 的质量默认候选：五轮对话完整、三项记忆全部保留、能记住花生过敏、没有替用户行动，长度控制5/5通过；平均首字0.468秒，单轮总耗时2.459秒。

`Qwen3-30B` 平均单轮仅0.903秒，但回答过短、角色感弱，并在正式复跑中漏掉花生过敏，不能作为当前默认。`Qwen3.6-27B-Fable` 角色语气较鲜明，但平均单轮7.403秒，三项普通记忆仅保留1项，也不推荐默认。

本轮只证明35B通过“五轮中性成年角色扮演基线”，尚未证明它通过16K/32K长记忆、多角色世界书、跨会话状态或边界专项。

## 测试设置

- 场景：虚构成年书店经理“林澈”，连续五轮对话；
- 关键记忆：蓝色旅行笔记、次日7:30火车、红伞、花生过敏；
- 行为要求：每轮60–180个中文字符、保持角色、不替用户决定或执行动作、能表达独立判断；
- 接口：SillyTavern 使用的 OpenAI-compatible 流式接口；
- 默认参数复刻：temperature 1、top_p 1、min_p 0、repetition penalty 1；
- 35B调参档：temperature 0.8、top_p 0.95、min_p 0.05、repetition penalty 1.05。

测试期间没有修改用户现有 SillyTavern 配置。

## 质量观察

### 35B 调参档

优点是记忆、节奏、完整度和人物口吻最均衡，调参后平均回复由111字降到96字，总耗时也略降。主要问题是会主动补写未提供的书签、章节、天气、店铺设备等细节，并偶尔出现过激表达。角色扮演允许适量创作，但关键用户事实、医疗信息与已发生动作不能凭空补全。

建议角色卡增加：

> 关键事实不得擅自补全；不要从健康信息推断心理状态；避免过激或惩罚性反应；每轮最多新增一个无风险环境细节。

### 30B

速度优势明显，但正式复跑平均只有32.2个中文字符，五轮全部低于要求；同时忘记7:30火车并忽略花生过敏。固定种子下前后运行表现也有波动，说明当前参数下稳定性不足。其模型实际上下文上限为40960，若实验使用，SillyTavern 上下文不得继续设为65536。

### 27B

角色语气比30B更明显，但响应慢、普通记忆弱，且会补写护照、车票等不存在的事实。它没有形成足以抵消速度和记忆劣势的默认价值。

## 最佳使用方法

当前推荐把35B作为质量档候选，使用：temperature 0.8、top_p 0.95、min_p 0.05、repetition penalty 1.05，并配合关键事实约束。30B只在“极低延迟比角色深度更重要”的短聊实验中保留，且上下文设为不高于40960；27B暂不进入默认路由。

在完成下一轮长上下文与世界书评测前，不直接改动现有 SillyTavern 默认设置。
