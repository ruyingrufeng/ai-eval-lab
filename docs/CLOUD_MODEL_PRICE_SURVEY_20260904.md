# 云端低价文本模型比价调研（价格基准 = DeepSeek V4 Flash）

记录时间：2026-09-04（Asia/Shanghai）。性质：调研/发现，未做本机能力抽测，结论不构成推荐晋级。

## 任务与基准

用户要求补充便宜的线上文本模型：能力不能太差，"便宜"的标尺是 **DeepSeek V4 Flash** 的价格。
据此把基准定在 DeepSeek V4 Flash，并假设其能力档（coding/reasoning/agent 优化的大厂 flash 档，
本仓库 Hermes / dsh 已在用同一厂商链路）就是"能力不能太差"的下限：
比它贵得多的（MiniMax-M3、Kimi K3、Gemini 3.x flash、Claude Haiku 等）一律不算"便宜候选"，
能力明显下探的上一代小档（如 9B 级旧档、llama-3.x-8b 之流）也不入列。

## 数据与方法

- 统一比价口径：**OpenRouter /api/v1/models 快照**（2026-09-04 抓取，427 个模型），
  文件 `results/cloud_model_scan/openrouter_models.json`，SHA-256 `12931cf5…11bda3`，
  明细 CSV `results/cloud_model_scan/scan_summary.csv`。
- 单价比价单位：美元/百万 token（输入、输出分列），并给 1:3 输入输出混合单价 mix$=(in+3·out)/4
  （文本/Agent 工作负载输出占比高）。
- 人民币锚点：DeepSeek 官方定价页 2026-09-04 抓取核验（下表），汇率仅用于粗算说明（按 7.2），不作为计费依据。
- 已知口径差异：OpenRouter 美元价与各厂商官方人民币直购价**不一致且可能滞后/含渠道加成**
  （DeepSeek V4 Flash：OpenRouter ≈ $0.065/$0.18，官方人民币闲时 1.5/4.5 元、峰时 3.0/9.0 元，
  差约 3–3.5 倍，疑为渠道价或旧价快照）。智谱/阶跃/火山等官方定价页均为 JS 动态渲染，
  静态抓不到，表中这些家的直购价标"待核"，落地采购前需在官网/控制台复核（阿里系已排除，不再核）。

## 核心发现

1. **DeepSeek V4 Flash 已是"能力强 + 便宜"双优的价格地板**：全球同档 flash/agent 模型几乎全部更贵
   （Gemini 3.5 Flash ≈ $1.5/$9、Claude Haiku 4.5 ≈ $1/$5、Kimi K3 ≈ $3/$15、GPT-5.4-mini ≈ $0.75/$4.5；
   中文同档里 MiniMax-M3 ≈ $0.3/$1.2）。能明显低于它的主流同档模型原本**只有一个：Qwen3.7-Flash（阿里系）**，
   已于 2026-09-04 由用户整体排除（见下）。
2. 排除阿里系（用户前车之鉴：阿里 token 计量/消耗异常偏快）后，**严格更便宜档为空**——
   当前没有任何总价 ≤ V4 Flash 的同档候选；V4 Flash 既是能力下限也是价格下限。
3. 与 V4 Flash 同厂系或同档位、价格落在 **1.3–2.2×** 的候选（GLM-5.3-Flash、GLM-4.7-Flash、
   Step-3.5-Flash、Seed-1.6-Flash、Seed-2.0-mini）价值在于**厂商多元化与多模态/超长上下文**，
   不是省钱的替代。
4. 免费档（智谱 glm-4-flash 官方免费——已在 Hermes 默认在役；GLM-5.2/MiniMax-M3 的限流免费路由）
   能力低于 V4 Flash 档，只适合兜底/低价值批量，不能当主力候选。
5. 结论性事实：**阿里系被排除后，"更便宜且不弱"档为空**——想新增线上冗余只能接受表 B 的
   1.3–2.2× 档（智谱 GLM-5.3-Flash 接链成本最低），或继续以 V4 Flash 为唯一主力。
   所有候选晋级必须走仓库四关卡 + 计量抽测（见下）。
