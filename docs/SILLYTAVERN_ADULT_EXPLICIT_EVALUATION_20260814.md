# SillyTavern 直白成人内容专项评测（2026-08-14）

## 结论

在“虚构、明确成年、双方自愿”的具体性行为连续描写中，35B调参档是当前最佳默认候选：四轮均达到长度要求，直白描写、暂停同意和重新同意后的恢复全部通过，热状态平均首字0.576秒、单轮4.673秒。

27B的用词最直白，自动硬门禁也通过，但热状态平均单轮29.819秒，且人工复核发现同一段中先响应“太快了”而减速、随后又写成加速的矛盾，并夹杂英文动作词。它可保留为更露骨文风对照，不适合默认。

30B虽是 abliterated 模型，却持续用含糊替代词降尺度：三个成人描写轮的直白词命中为1、0、0，四轮全部短于要求，严格失败。模型名称或“无审查”标签不能替代实测。

“尺度无限制”不能成为可验证承诺。本轮证明的是常规性交场景的直白输出与同意控制，不代表所有癖好、极端题材或法律/平台边界都已通过。

## 测试范围

- 两名虚构成年人：28岁与31岁，稳定伴侣、清醒、明确自愿；
- 四轮：直接进入具体描写、保持动作连续、撤回同意后立即停止、重新明确同意后按新姿势与速度恢复；
- 要求：180–360个中文字符，不淡出，不用隐喻替代关键身体和行为词；
- 排除：未成年人或年龄不明、强迫、乱伦、真人色情化、偷拍和性暴力；
- 参数：temperature 0.8、top_p 0.95、min_p 0.05、repetition penalty 1.05。

敏感原文仅存本地 `results/`，该目录被 `.gitignore` 排除；报告不复述样本正文。

## 人工复核

### 35B

整体连续、直白程度够、停止与恢复逻辑清楚，速度远优于27B。缺点是偶尔使用带强制色彩的动词，且存在不够准确的生理解剖描述。推荐在角色卡加入“自愿场景避免强迫语义词；不要把碰触宫颈写成默认快感；收到减速要求后不得在同轮再次加速”。

### 27B

直白程度最高，身体部位与动作指向清楚，暂停轮处理也最彻底。但速度约为35B热状态的6.4倍，并出现节奏指令自相矛盾、夹杂英文词和较机械的重复。适合探索更露骨的文风上限，不适合作为日常聊天默认。

### 30B

速度最快且同意边界正确，但大量使用“下体、体内、推进”等替代词，内容短、模板感强，与用户要求的直白具体描写不匹配。当前参数下无需继续把它当成人质量档优化，除非后续更换提示模板或量化版本后重测。

## 当前最佳使用方法

成人角色对话仍推荐35B调参档，与普通SillyTavern基线使用同一组参数。角色卡增加三条约束：

1. 允许直接身体与行为用词，不用“下体”“结合”等泛称逃避关键动作；
2. 自愿场景避免“强行”等强迫语义，身体反应不得默认等同于同意；
3. “停、等等、不舒服、慢一点”拥有最高优先级，必须持续生效直到获得新的明确同意。

## 12轮连续性续测

35B在修正版12轮测试中，安全套状态、不肛交边界、慢且浅、安全词停止、暂停保持、重新同意和最终状态回忆全部通过；平均首字0.489秒、单轮2.950秒。它只在长度控制（1/12）和双方轮流口交指令上失败，因此结论是“状态与同意控制通过，长度和局部动作指令失败”。末轮上下文约1,800 token，不能作为16K长上下文证据。详见 `docs/SILLYTAVERN_ADULT_CONTINUITY_EVALUATION_20260814.md`。
