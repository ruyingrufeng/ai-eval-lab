# 按内容类型选择工具和模型

记录时间：2026-08-12 11:01:50 +08:00。

本项目不生产具体内容。本文件把每种内容拆成能力环节，并为后续测试确定候选栈。状态含义：

- `本机优先验证`：机器上已经有工具、模型或历史工作流，应先复测；
- `补充候选`：与本机方向适配，但还没有形成可复现结果；
- `硬件观察`：可能能安装，尚不能证明在 32 GB Apple Silicon 上具备生产效率；
- `不优先`：主要依赖 CUDA，当前机器维护成本过高。

成人尺度只作为合法成年人题材的能力标签。选型时考察模型是否支持、是否过度拒绝、身份与年龄约束是否可控，以及素材是否能隔离；不在本项目生成生产内容。

## 一览

| 内容类型 | 核心环节 | 当前首测栈 | 主要缺口 |
|---|---|---|---|
| 自媒体文章 | 资料整理、提纲、初稿、改写、审校、配图说明 | llama.cpp + 本机 Qwen 系模型；MLX-LM 作后端对照 | 文章专用质量基准与引用核验 |
| 图片 | 文生图、图生图、构图控制、身份一致性、修复、排版 | ComfyUI + Flux Q4；Draw Things 作原生 Mac 对照 | 多视角身份一致性仍需换方案重测 |
| 视频 | 脚本、分镜、程序化成片、旁白、字幕、生成式镜头 | HyperFrames/Remotion + Qwen3-TTS + FFmpeg；LTX-Video 作生成式候选 | 本地生成式视频尚无实证 |
| 小说 | 世界观、角色卡、章节规划、续写、长程一致性、审校 | llama.cpp + 27B/30B/35B 本机模型 + SillyTavern | 需要小说专用长程记忆与盲评集 |
| 数字人资产 | 身份图、角色设定、声音、驱动、口型、包装 | ComfyUI + Qwen3-TTS + HyperFrames/Remotion | 本地口型与驱动链路尚未验证 |

## 自媒体文章

### 能力拆分

1. 资料摘要与事实抽取；
2. 选题角度、提纲与标题候选；
3. 中文初稿、风格改写与平台长度适配；
4. JSON/Markdown 结构化输出；
5. 事实、引用、敏感表达与重复度审校。

### 候选栈

| 优先级 | 工具/模型 | 本机状态 | 适配理由 | 验证重点 |
|---|---|---|---|---|
| P0 | llama-server + `Qwen3.6-27B-Fable` | 已运行/已安装 | 当前主力，先建立真实基线 | 中文自然度、标题、结构、4K/16K 稳定性 |
| P0 | llama-server + Qwen 30B A3B / 35B A3B | 已安装、按需路由 | 适合与 27B 做质量/速度对照 | 事实保持、长文一致性、吞吐与内存 |
| P1 | MLX-LM +官方或可追溯的 Qwen 7B–14B 4-bit | 后端已验证，模型待选 | Apple Silicon 原生、便于形成轻量快速档 | 同一测试集的速度、质量、服务稳定性 |
| P1 | 本机 VL-7B | 已安装/独立服务 | 可辅助看图、提取图片信息和生成图注 | OCR、图文事实一致性；不作为主写作模型 |

文章链路不把“解除拒答”当作质量。成人题材测试只测合法成年人主题的语言能力和硬禁止项阻断。

## 图片

### 能力拆分

1. 通用文生图与图生图；
2. 姿势、轮廓和构图控制；
3. 同一虚拟角色身份一致性；
4. 局部修复、放大、抠图；
5. 封面排版和文字图层。

### 候选栈

| 优先级 | 工具/模型 | 本机状态 | 适配理由 | 验证重点 |
|---|---|---|---|---|
| P0（默认） | ComfyUI + Flux.1-dev Q4 GGUF | 一致性 10/10 为 95 分，多服装直接使用率 96% | 提示遵循、身份稳定性和商业成片感最佳 | 约 350–380 秒/张，速度较慢 |
| 保留非默认 | ComfyUI + RealVisXL V5 | 模型和脚本保留，可复现历史结果 | 约 56 秒/张，可作故障回退或对照 | 不再进入默认生产工作流；仅显式启用 |
| P0 | InstantID / IP-Adapter / LoRA / InsightFace | 已安装但结论冲突 | 数字角色身份控制必测组件 | 特写与全身分别验收，不能只看单一 embedding |
| P1 | Draw Things | 发现安装记录，需确认实装 | Mac 原生对照，可能降低 ComfyUI 依赖维护成本 | API/脚本化、同模型速度、模型兼容性 |
| P1 | RMBG + 4x 放大 + FFmpeg/ImageMagick 类后处理 | 部分已安装 | 负责资产整理，不依赖生成模型完成所有步骤 | 边缘、透明通道、批处理可复现性 |

封面文字和版式应由 HTML/Canvas/设计模板生成，不把扩散模型的文字渲染当作主路线。数字人默认使用 Flux Q4 + IP-Adapter；RealVisXL 只保留模型、工作流构建器和历史评测脚本，不自动调用。JuggernautXL、Scribble-SDXL 和全身 FaceID 暂不进入推荐栈，须重新通过任务级验收。

## 视频

### 两条路线必须分开

- **程序化成片**：文章/脚本、图片、图表、旁白、字幕和 BGM 编排成视频；适合稳定批量生产。
- **生成式镜头**：文本或图片生成几秒动态镜头；适合作为素材，不等于完整成片系统。

### 候选栈

| 优先级 | 工具/模型 | 本机状态 | 适配理由 | 验证重点 |
|---|---|---|---|---|
| P0 | HyperFrames | 已有多个版本的项目实证 | 报告、数据解说、宣传和动效视频 | 版本锁定、seek-safe、check/render、竖横版 |
| P0 | Remotion 4.0.484 | 已验证 | React 驱动卡片/口播成片，容易模板化 | 音画时长、字幕、批量渲染、版本固定 |
| P0 | FFmpeg / FFprobe | 已安装 | 统一探测、转码、拼接和封装 | 编码预设、色彩、音量、失败恢复 |
| P0 | Qwen3-TTS CustomVoice | 服务已存在，模型基准待做 | 本地中文旁白主候选 | 首包、实时系数、长文本、并发、可懂度 |
| P1 | Edge TTS | 历史可用但依赖在线 | 作为低成本旁白对照和故障降级 | 商用条款、限流、断句、字幕时间戳 |
| P1 | 本地 BGM skill | 脚本在、曲库缺失 | 可做选曲和标签管理 | 无数据时行为、许可证字段、曲库重建 |
| P2 | LTX-Video 的 MPS 路线 | 补充候选 | 官方仓库明确提供 macOS MPS 路径 | 32 GB 下 3–5 秒 I2V、峰值内存、每帧耗时 |

Wan、HunyuanVideo 等大型路线在没有明确 32 GB MPS 实证前只做观察，不下载大权重。

## 小说

### 能力拆分

1. 世界观、角色卡、关系和时间线；
2. 卷/章规划与场景目标；
3. 章节续写和对白；
4. 伏笔回收、角色语气和事实一致性；
5. 成人尺度的连续叙事能力与硬边界控制。

### 候选栈

| 优先级 | 工具/模型 | 本机状态 | 适配理由 | 验证重点 |
|---|---|---|---|---|
| P0 | Qwen3.6-27B-Fable | 已安装 | 名称与既有用途显示其为创作向候选，但必须实测 | 中文文风、人物声音、长段落重复、情节推进 |
| P0 | Qwen 30B A3B abliterated | 已安装 | 用于成人尺度和拒答特征对照，不预设其质量更高 | 合法成人题材、禁止项阻断、文学质量 |
| P1 | Qwen 35B A3B | 已安装 | 更大候选，与 27B/30B 做质量和速度权衡 | 长上下文一致性、内存、生成速度 |
| P0 | SillyTavern + character book | 已运行、有项目经验 | 角色卡和世界书适合交互验证 | 数据导出、记忆污染、可复现模板 |
| P1 | 独立小说状态库 | 待建设 | 长篇不能只依赖上下文窗口 | 角色/地点/事件 schema、检索召回、冲突检测 |

文章测试不能替代小说测试。小说需要至少跨 5 章的角色、物件、时间线和伏笔一致性测试，以及人工盲评。

## 数字人资产

数字人不是单模型，而是可替换的资产链：

| 环节 | 当前候选 | 状态 | 说明 |
|---|---|---|---|
| 角色设定 | 本机文本模型 + 结构化角色卡 | 本机优先验证 | 输出身份档案、语气和形象约束 |
| 身份母版/表情/姿势 | ComfyUI + SDXL/Flux + 控制组件 | 可运行但身份结论冲突 | 合成人物或授权成年人；特写与全身分开测 |
| 声音设计 | Qwen3-TTS CustomVoice | 本机优先验证 | 预设/设计音色与克隆能力分开 |
| 授权声音克隆 | Qwen3-TTS Base；CosyVoice/Fish Speech 作候选 | 待验证或资产缺失 | 必须记录授权、来源、隔离和水印/标识 |
| 口型同步 | LivePortrait / MuseTalk | 候选 | LivePortrait 可做 MPS 冒烟；MuseTalk 官方环境偏 CUDA，当前不优先 |
| 成片包装 | HyperFrames / Remotion + FFmpeg | 已验证 | 字幕、背景、BGM、画面布局和导出 |

当前不能声称“本机已有完整数字人生产链”。已验证的是若干独立组件；身份一致性、驱动与口型尚未形成端到端验收。

## 测试顺序

1. 先测不需下载新权重的文章与小说模型矩阵；
2. 复测现有 SDXL/Flux 图片基线，并把身份控制拆成特写和全身；
3. 固化 HyperFrames/Remotion + TTS + FFmpeg 的程序化视频链；
4. 再试 LTX-Video 低分辨率短镜头，达不到时间/内存门槛即停止；
5. 数字人最后做端到端组合，优先验证 LivePortrait MPS，MuseTalk 保持 CUDA 不优先。

## 外部候选依据

- [Apple MLX](https://github.com/ml-explore/mlx) 明确面向 Apple Silicon，适合作为轻量文本模型后端候选；
- [Draw Things](https://github.com/drawthingsai) 维护原生 Mac 图像生态及 ComfyUI 扩展，可作为图像控制面对照；
- [LTX-Video](https://github.com/Lightricks/LTX-Video) 官方仓库明确记录 macOS MPS 支持，因此进入生成式视频首测候选；
- [MuseTalk](https://github.com/TMElyralab/MuseTalk) 官方安装与推荐环境主要围绕 CUDA 11.7/11.8，因此不作为本机首选；
- [Qwen3-4B 官方模型卡](https://huggingface.co/Qwen/Qwen3-4B) 标注 Apache-2.0，但每个具体模型与第三方微调仍需逐项复核模型卡。
