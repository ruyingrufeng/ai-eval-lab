# Flux 高质量身份母版两 seed 确认（2026-08-14）

## 【结论】

三张素材可以组成有效身份母版，但 Flux IP-Adapter 仍未通过“精确身份 + 全身构图”生产验收。

三张母版覆盖完整：正脸偏航约 −4.5°、3/4 脸约 −22.2°、偏侧脸约 −49.4°；两两 InsightFace 相似度为 0.6125–0.7433，身份一致性强。

以正脸母版作为 Flux IP-Adapter 0.85 输入生成两个 seed 后：

- 输出相互相似度 0.6683，说明模型生成了一个较稳定的新角色；
- 输出对三张母版的平均相似度只有 0.3089 和 0.3478；
- 对正脸母版相似度为 0.3342 和 0.3703，只有 1/2 越过 0.35；
- 两张都被拉成大半身，完整全身成功率 0/2。

因此 Flux IP-Adapter 适合“基于参考脸生成相近、相对稳定的新角色”，不适合“精确复制指定身份的全身图”。

## 【风险】

- 高质量正脸参考会强化肖像构图偏置，即使提示词明确要求全身，本轮仍 0/2 全身。
- 两张输出彼此很像，但不等于忠实复制母版；内部一致性与参考身份一致性必须分开评价。
- 资源最低空闲内存 36%，仍需串行；但 swap 净增加仅 240.75 MiB，没有出现 ControlNet 组合的快速失控。
- 当前节点不支持真正的多图身份融合。

## 【方案】

- 停止把 Flux IP-Adapter 作为“精确锁脸全身图”的默认路线。
- 保留它用于角色近似、风格延续和肖像类素材，此时应明确结果是“相近角色”，不是同一身份。
- 需要指定身份的全身图时，先用普通 Flux 保证完整构图，再使用 FaceID/InstantID、角色 LoRA 或后期换脸处理脸部；不要让高权重正脸参考直接主导全图生成。
- 三张母版本身合格，应保留为后续方法的统一验收集。

## 【下一步】

如果继续身份链，优先验证“两阶段路线”：普通 Flux 生成全身底图，再用正脸母版做局部身份替换。只需 2 张底图，验收标准为全身 2/2、平均身份相似度 ≥0.35、脸部无明显拼接感。若仍不通过，则本地身份链停止，角色一致性改交角色 LoRA 或在线编辑模型。
